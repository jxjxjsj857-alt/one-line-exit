The One-Line Exit: a program that writes the funniest single-line resignation letter it can — one line, 124 characters, no padding. After three years of hearing "we're a family here," the letter writer has decided to get emancipated.

## Run it

```sh
python3 main.py
```

It writes the resignation letter to `/output/entry.txt`.
